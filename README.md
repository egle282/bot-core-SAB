# 🧠 SaveAs Pro — Your AI-Powered Second Brain in Telegram

> **Сохраняйте знания → Находите по смыслу → Спрашивайте свой личный ИИ**  
> Автономный AI-ассистент базы знаний прямо в Telegram с поддержкой RAG (Retrieval-Augmented Generation), локальной векторизацией данных, авто-аннотацией заметок и веб-интерфейсом.
>
> 🔒 **100% Приватно:** Ваши заметки и мысли не утекают в облако — обработка происходит локально через **Ollama** (`llama3.2:1b`, `nomic-embed-text`) и хранилище SQLite / pgvector.  
> ⚡ **Готов к развертыванию:** Запуск локально скриптом `setup.sh` или в контейнерах `docker compose up -d`.

## 🎯 Какие боли и проблемы решает SaveAs Pro?

В эпоху информационного перегруза каждый день мы сохраняем десятки постов, статей, идей и скриншотов в «Избранное» (Saved Messages) Telegram или заметки, где они превращаются в «цифровое кладбище».

| Проблема пользователя / бизнеса | Как её решает SaveAs Pro |
| --- | --- |
| ❌ **«Кладбище закладок» в Telegram:** сотни пересланных постов и ссылок в «Избранном», в которых невозможно ничего найти через неделю. | ✅ **Автоматическая аннотация и тегирование:** при команде `/save` бот на лету формирует суть заметки в 1 предложение и строит векторный индекс. |
| ❌ **Бесполезный поиск по ключевым словам:** если вы забыли точное слово из статьи (например, ищете «как работают языковые модели», а в посте было написано «механизм внимания трансформаторов»), поиск Telegram выдаст 0 результатов. | ✅ **Семантический векторный поиск (`/search`):** поиск по **смыслу**, а не по совпадению букв. Бот понимает синонимы, контекст и суть вопроса. |
| ❌ **Утечка конфиденциальных данных в облачные LLM:** отправка личных мыслей, рабочих регламентов или коммерческих заметок в сторонние API (OpenAI/Anthropic) несет риски безопасности. | ✅ **Zero-Cloud Privacy:** генерация ответов и векторизация выполняются локально на вашем компьютере/сервере через Ollama. Данные никогда не покидают ваш контур. |
| ❌ **«Галлюцинации» ИИ:** стандартные чат-боты выдумывают факты, когда вы задаете вопрос по своим прошлым заметкам. | ✅ **RAG строго по вашей базе знаний (`/ask`):** модель ищет только релевантные фрагменты из ваших сохраненных данных и отвечает строго по фактам. Если данных нет — честно говорит «Не знаю». |
| ❌ **Сложность развертывания AI-стека:** обычно для RAG нужно настраивать векторную базу, писать парсеры, связывать эмбеддинги и веб-сервер. | ✅ **Решение «из коробки» (Out-of-the-Box):** единый скрипт автоматической настройки (`./setup.sh`) и готовый `docker-compose.yml` со всеми сервисами. |

## 🚀 Основные сценарии использования

### 1. Сохранение информации в 1 клик (`/save`)
- **Текстовая заметка:** `/save Сравнение подходов к шардированию баз данных: Range vs Hash partitioning`
- **Пересылка постов:** просто перешлите в диалог с ботом любой пост из Telegram-канала, PDF-документ или изображение и добавьте подпись `/save`. Бот сохранит контент, выделит главное и создаст эмбеддинг.

### 2. Поиск по смыслу (`/search`)
- Введите: `/search распределенные очереди`
- Бот найдет заметки про Kafka, RabbitMQ или Redis Streams, даже если слова «распределенные очереди» буквально не встречались в тексте.

### 3. Диалог с вашей памятью (`/ask` — RAG-режим)
- Задайте вопрос: `/ask Какие выводы мы сделали на ретро по мобильному приложению?`
- Бот извлечет релевантные заметки и выдаст лаконичный синтезированный ответ со ссылкой на сохраненные тезисы.

### 4. Ранний доступ и монетизация (`early`)
- Бот генерирует персональный QR-код на ранний доступ и скидку для ваших пользователей, связывая Telegram с базой Notion и аналитикой PostHog.

## ⚡ Быстрый старт (Локально за 3 шага)

### 1. Клонируйте репозиторий

```bash
git clone https://github.com/egle282/bot-core-SAB.git
cd bot-core-SAB
```

### 2. Запустите автоматическую настройку

Скрипт проверяет версии Python и Node.js, развертывает виртуальное окружение, ставит зависимости и подтягивает модели Ollama:

```bash
chmod +x setup.sh
./setup.sh
```

### 3. Заполните токен бота и запустите

Скопируйте шаблон окружения и укажите токен Telegram-бота:

```bash
# Файл .env создается автоматически скриптом setup.sh
# Укажите ваш TELEGRAM_BOT_TOKEN, полученный у @BotFather
nano .env
```

Запуск Telegram-бота:

```bash
source venv/bin/activate
python backend/main.py
```

Запуск Web API (FastAPI) и Mini App (Next.js):

```bash
# Терминал 1: Запуск API
source venv/bin/activate
uvicorn backend.api.main:app --reload --port 8000

# Терминал 2: Запуск фронтенда
cd frontend && npm run dev
```

## 🐳 Запуск через Docker Compose

Для продакшн-запуска с PostgreSQL (pgvector) и Redis:

```bash
cp .env.example .env
# Заполните TELEGRAM_BOT_TOKEN в файле .env

docker compose up -d --build
```

Все сервисы (бот, FastAPI, PostgreSQL с расширением pgvector, Redis) поднимутся автоматически.

## 📋 Команды Telegram-бота

- `/start` — Интерактивное приветствие и краткий гид по боту.
- `/save <текст>` — Сохранить заметку с автоматической генерацией саммари и эмбеддинга.
- `/search <запрос>` — Гибридный семантический поиск по вашей базе заметок.
- `/ask <вопрос>` — Задать вопрос своему персональному архиву (RAG).
- `early` — Получить персональный QR-код для раннего доступа.
